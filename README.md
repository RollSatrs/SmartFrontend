# Smart City Abai: веб-сайт

Сайт платформы «Идеи для региона» (область Абай). Next.js 16, Tailwind 4, shadcn/ui. Работает с общим backend
(NestJS), тем же, что мобильные приложения.

**Житель:** подать идею (фото, точка на карте, улица, помощь ИИ), следить за статусами, оценить результат,
рейтинг районов.
**Госорган:** обращения со сроками (15 дней), фильтры, карта обращений, назначение, смена статуса с быстрыми
ответами, аналитика недели, районы и нагрузка сотрудников.

## Кому адресовано обращение

ИИ определяет категорию, сайт по категории показывает ответственный орган с адресом и телефоном (`lib/organs.ts`).
Откуда взяты названия и что ещё нужно уточнить: [ORGANS_SOURCES.md](ORGANS_SOURCES.md).

Тип обращения «проблема / идея» включается сам, когда сервер сообщает о поддержке в `GET /health` (поле `features`).

## Как это устроено

Сайт обращается к backend только через свой адрес `/api/...`: Next.js проксирует запросы на сервер
(`rewrites` в `next.config.ts`). Поэтому страница по HTTPS работает с backend по HTTP, а куки входа остаются
на домене сайта. Адрес backend задаётся переменной `BACKEND_URL` (по умолчанию боевой сервер проекта).

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
npm run build && npm start
npm test             # vitest
```

## Публикация на Vercel

1. Импортируйте репозиторий в Vercel (Framework Preset: Next.js, остальное по умолчанию).
2. В Environment Variables при необходимости задайте `BACKEND_URL` (по умолчанию `http://194.238.41.34:3002`).
3. Deploy. Проверьте: `https://<сайт>.vercel.app/api/health` отвечает, вход и создание идеи с фото работают.

Или из папки проекта: `npx vercel login`, затем `npx vercel --prod`.

## Важно

- Регистрация сотрудника госоргана требует код приглашения (`GOV_INVITE_CODE` на backend). Без изменений
  backend из репозитория `SmartBackend` ветка с этой защитой ещё не выложена, поэтому поле кода пока лишнее.
- Фото сжимаются в браузере до 1600 px, чтобы запрос проходил через прокси.
- Улица и дом определяются через Nominatim (OpenStreetMap), не чаще одного запроса в секунду, результат
  запоминается в браузере.
- Карта: Leaflet и OpenStreetMap, атрибуция обязательна и уже показана.
